## ✨ Features

### Core Features
- **🎯 Text-to-Image Generator** - Transform your imagination into visual art
- **🎨 6 Unique Styles** - Photo, Digital Art, Concept Art, Anime, 3D Render, Oil Painting
- **📐 Multiple Aspect Ratios** - 1:1, 16:9, 9:16, 4:3, 3:4
- **⚡ Quality Slider** - Balance between speed and quality

### Smart Features
- **✨ Prompt Enhancer** - AI-powered keyword suggestions for better results
- **💡 Inspiration Prompts** - Random creative prompts to spark your imagination
- **🚀 Quick Prompts** - Pre-made prompts for instant creativity

### Organization
- **🖼️ Gallery** - Browse all your creations
- **📜 History** - Track your generation history
- **❤️ Favorites** - Save your best work
- **⬇️ Download** - Export images as PNG

## 🚀 Quick Start

### Running Locally

```bash
# Clone the repository
git clone https://github.com/antono4/firefly.git
cd firefly

# Start a local server (Python)
python3 -m http.server 8080

# Or using Node.js
npx serve .

# Or using PHP
php -S localhost:8080
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.

### Running with VS Code Live Server

1. Install the "Live Server" extension
2. Right-click on `index.html`
3. Select "Open with Live Server"

## 🎨 Usage

### Creating an Image

1. **Enter a Prompt** - Describe what you want to create in the text area
2. **Choose a Style** - Select from Photo, Digital Art, Concept Art, Anime, 3D Render, or Oil Painting
3. **Set Aspect Ratio** - Choose the dimensions that fit your needs
4. **Adjust Quality** - Use the slider for faster or higher quality results
5. **Click "Generate Magic"** - Watch your imagination come to life!

### Enhancing Prompts

Click the **Enhance** button to automatically add style-specific keywords to your prompt for better results.

### Using Quick Prompts

Click on any quick prompt button (Japanese Garden, Cyberpunk City, Fantasy Dragon, Cozy Coffee Shop) to instantly load a creative prompt.

## 💡 Tips for Better Results

1. **Be Specific** - The more detailed your prompt, the better the output
2. **Use Style Keywords** - Add words like "cinematic", "dramatic", "detailed"
3. **Try Different Styles** - Each style creates unique interpretations
4. **Experiment with Ratios** - Different ratios work better for different subjects
5. **Use Enhancer** - Let the AI add professional keywords to your prompt
